# PSNet5 paper figures

Generated by `python analysis/psnet5/make_paper_figures.py` with seed 20261004 and up to 200000 displayed points per area. Both PNG and PDF are provided. Point-cloud views are deterministic samples, not full-density renders; XY views can overlap vertically. Class examples are 2 m local regions, not isolated object instances. Error crops are illustrative regions selected from sampled errors.

- 01: RGB and ground-truth labels for the four areas.
- 02: Area 3 ground truth and weighted epoch-39 predictions, identical sampled points.
- 03: Area 3 confusion matrix, row-normalized by ground-truth class; source counts are `../results/weighted_ce_epoch39_area3/confusion_vote_01.csv`.
- 04: Per-class Area 3 IoU for the unweighted baseline and weighted model.
- 05: Local examples of the five ground-truth classes in Area 3.
- 06: Illustrative regions of i-beam-to-pipe and pump-to-pipe errors.

Source data and the benchmark cache are external to Git; see script options and the repository README. Area 3 informed development and is not an untouched test set.
